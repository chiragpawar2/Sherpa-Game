Sherpa — The Warm Way WebGL build

Open this folder through a web server. Browsers block Unity's data files when index.html is opened directly from file://.

From this folder, run:

  python3 -m http.server 8000

Then visit:

  http://localhost:8000/

The build was produced with Unity 6000.6.9f1 for WebGL, with zero build errors and zero warnings.
